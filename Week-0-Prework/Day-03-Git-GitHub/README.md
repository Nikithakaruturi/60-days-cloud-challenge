# Hands-on Practice

I created a local Git repository and practiced the basic Git workflow:

- Created a Git repository using git init
- Created and viewed a README.md file
- Checked the repository status using git status
- Added the file to the staging area using git add
- Created a commit using git commit
- Viewed the commit history using git log --oneline
- Configured the default branch as main

# What I Learned

I learned how Git tracks changes in files and how commits are used to save changes in a repository. I also learned the basic workflow of checking changes, staging files, and creating commits.
