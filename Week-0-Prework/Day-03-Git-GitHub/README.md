**Week 0 – Day 3: Git & GitHub Basics**

**Objective**
Learn the basics of Git and GitHub and understand how version control is used to manage project files.

**Topics Practiced**
- Git basics
- Git repositories
- Git status
- Staging files
- Git commits
- Git history
- Git branches
- GitHub repositories
- Push and pull concepts

**Git Commands Practiced**

`git init`  
`git status`  
`git add`  
`git commit`  
`git log`  
`git diff`  
`git branch`  
`git remote`  
`git push`  
`git pull`  
`git clone`

**Hands-on Practice**

I created a local Git repository and practiced the basic Git workflow:

1. Created a Git repository using `git init`
2. Created and viewed a `README.md` file
3. Checked the repository status using `git status`
4. Added the file to the staging area using `git add`
5. Created a commit using `git commit`
6. Viewed the commit history using `git log --oneline`
7. Configured the default branch as `main`

**What I Learned**

I learned how Git tracks changes in files and how commits are used to save changes in a repository. I also learned the basic workflow of checking changes, staging files, and creating commits.
