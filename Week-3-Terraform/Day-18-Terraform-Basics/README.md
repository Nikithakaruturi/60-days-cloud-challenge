## Terraform Workflow

1. Write Terraform configuration
2. terraform init
3. terraform plan
4. terraform apply
5. terraform destroy

## Key Concepts

Terraform is an Infrastructure as Code tool used to define and manage infrastructure through configuration files.

A provider allows Terraform to interact with platforms such as AWS.

A resource represents infrastructure that Terraform manages.
