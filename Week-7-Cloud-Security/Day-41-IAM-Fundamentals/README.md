**Day 41 – Learn IAM Fundamentals**

**Objective**

Understand AWS Identity and Access Management (IAM) and how it controls access to AWS resources.

**Topics Covered**
- IAM fundamentals
- IAM users
- IAM user groups
- IAM roles
- IAM policies
- Principle of least privilege

**Practical Tasks**
- Explored the AWS IAM dashboard.
- Reviewed the Users, Groups, Roles, and Policies sections.
- Reviewed the AWS-managed ReadOnlyAccess policy.
- Studied how IAM permissions control access to AWS services.

**Key Learning**

IAM helps manage identities and permissions securely in AWS. The principle of least privilege ensures that users and applications receive only the permissions required for their tasks.

**Result**

Learned the basic concepts of AWS IAM and how identity-based permissions help secure cloud resources.
