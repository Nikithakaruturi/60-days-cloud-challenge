**Day 43 – Create Limited IAM Users and Roles**

**Objective**

Learn to create IAM users, groups, roles, and custom policies using the principle of least privilege.

**Topics Covered**
- IAM user creation
- IAM group creation
- IAM role creation
- Custom IAM policies
- Least-privilege permissions

**Practical Tasks**
- Created a custom S3 read-only IAM policy.
- Created an IAM group and assigned the custom policy.
- Created a limited IAM user and added it to the group.
- Created an EC2 service role with restricted S3 permissions.
- Reviewed the permissions assigned to the user and role.

**Key Learning**

IAM users, groups, roles, and policies help control access to AWS resources. Custom policies can restrict permissions to specific resources and actions.

**Result**

Practiced creating limited IAM identities and permissions using the principle of least privilege.
