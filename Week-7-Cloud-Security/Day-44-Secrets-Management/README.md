**Day 44 – Learn Secrets Management**

**Objective**

Understand how sensitive information is securely stored, accessed, and managed in cloud environments.

**Topics Covered**

- Meaning of secrets management
- Passwords, API keys, tokens, and database credentials
- Secure storage of sensitive information
- Environment variables
- Secret rotation
- Access control and permissions
- AWS Secrets Manager
- AWS Systems Manager Parameter Store
- AWS KMS basics

**Key Learnings**

- Sensitive credentials should never be hardcoded in application source code.
- Secrets should be stored securely.
- Only authorized applications and users should access secrets.
- Secret rotation helps reduce the risk of compromised credentials.
- IAM controls access to secrets.
- Encryption protects sensitive information.

**Outcome**

Learned the fundamentals of secrets management and the purpose of AWS Secrets Manager.
