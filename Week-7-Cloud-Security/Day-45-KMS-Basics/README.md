**Day 45 – Learn KMS Basics**

**Objective**

Understand AWS Key Management Service and how encryption keys protect sensitive cloud data.

**Topics Covered**

- Introduction to AWS KMS
- Encryption and decryption
- Symmetric encryption
- Asymmetric encryption
- AWS managed keys
- Customer managed keys
- Key policies and permissions
- Key rotation
- KMS integration with AWS services

**Key Learnings**

- AWS KMS helps create and manage cryptographic keys.
- Encryption protects sensitive information.
- Decryption converts encrypted data into readable information.
- Key policies control access to encryption keys.
- Key rotation helps maintain security.
- KMS integrates with services such as S3, EBS, and RDS.

**Outcome**

Learned the fundamentals of AWS KMS and the importance of encryption and key management in cloud security.
