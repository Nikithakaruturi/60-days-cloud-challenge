**Day 46 – Enable CloudTrail and Review Logs**

**Objective**

Understand AWS CloudTrail and how it records account activity for auditing and security monitoring.

**Topics Covered**

- Introduction to AWS CloudTrail
- CloudTrail events
- Management events
- Data events
- Event history
- Trails
- CloudTrail log storage
- Reviewing event details
- Security auditing and investigation

**AWS Console Practice**

- Opened AWS CloudTrail.
- Explored Event history.
- Reviewed a CloudTrail event.
- Identified event name, event time, username, event source, and AWS region.
- Explored the Trails section and checked the existing trail configuration.

**Key Learnings**

- CloudTrail records activity in an AWS account.
- Event history helps review recent management events.
- Events contain details about account activity.
- Trails can deliver logs to an S3 bucket.
- CloudTrail helps investigate account activity and security events.

**Outcome**

Learned the fundamentals of AWS CloudTrail and reviewed account activity for cloud security monitoring.
