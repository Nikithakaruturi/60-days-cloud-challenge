**Day 47 – Read About Cloud Security Patterns**

**Objective**

Understand common cloud security patterns and how they protect cloud infrastructure, applications, and data.

**Topics Covered**

- Cloud security patterns
- Least privilege access
- Defense in depth
- Data encryption
- Network security
- Logging and monitoring
- Secrets management
- Backup and recovery

**AWS Services Reviewed**

- IAM
- AWS KMS
- AWS Secrets Manager
- AWS CloudTrail
- Security Groups
- AWS Backup

**Key Learnings**

- Least privilege limits unnecessary access.
- Defense in depth uses multiple security layers.
- Encryption protects sensitive information.
- Network security controls traffic to cloud resources.
- CloudTrail helps monitor account activity.
- Secrets should be stored securely.
- Backups support data recovery.

**Outcome**

Learned common cloud security patterns and how AWS services help protect cloud infrastructure and applications.
