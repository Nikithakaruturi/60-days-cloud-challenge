**Day 48 – Learn Metrics and Prometheus**

**Objective**

Understand monitoring metrics and learn how Prometheus collects and stores metrics for infrastructure and applications.

**Topics Covered**

- Introduction to monitoring
- Understanding metrics
- Difference between metrics, logs, and traces
- Introduction to Prometheus
- Prometheus architecture
- Prometheus exporters
- Time-series data

**Common Metrics**

- CPU usage
- Memory usage
- Disk usage
- Network traffic
- Application request count
- Application error rate

**Key Learnings**

- Monitoring helps track system and application health.
- Metrics provide numerical information about system performance.
- Prometheus is an open-source monitoring and alerting toolkit.
- Prometheus collects metrics from configured targets.
- Exporters expose metrics for Prometheus to collect.
- Prometheus stores metrics as time-series data.

**Practical Learning**

- Read the official Prometheus overview.
- Explored Prometheus architecture and components.
- Learned how metrics are collected and stored.

**Outcome**

Understood monitoring fundamentals, common system metrics, and the basic working principles of Prometheus.
