**Day 51 – Monitor Docker Containers**

**Objective**

Understand how to monitor Docker containers and inspect their resource usage, performance, and operational status.

**Topics Covered**

- Docker container monitoring
- CPU usage monitoring
- Memory usage monitoring
- Network input and output
- Block I/O
- Container logs
- Container health status

**Docker Commands Practiced**

```bash
docker ps
docker stats
docker inspect
docker logs
docker top
```

**Key Learnings**

- `docker ps` displays running containers.
- `docker stats` provides live resource usage information.
- `docker inspect` displays detailed container configuration.
- `docker logs` helps review container output.
- `docker top` displays processes running inside a container.
- Monitoring helps identify resource usage and container issues.

**Practical Implementation**

- Listed running Docker containers.
- Monitored CPU and memory usage.
- Explored network and block I/O statistics.
- Inspected container details and logs.
- Reviewed processes running inside containers.

**Outcome**

Learned how to monitor Docker containers and inspect their resource usage, logs, and operational status.
