**Day 52 – CloudWatch or Cloud-Native Monitoring**

**Objective**

Understand cloud-native monitoring and learn how AWS CloudWatch helps monitor cloud resources.

**Topics Covered**

- Introduction to cloud monitoring
- AWS CloudWatch overview
- CloudWatch Metrics
- CloudWatch Logs
- CloudWatch Alarms
- EC2 monitoring
- Difference between metrics and logs

**Key Learnings**

- CloudWatch collects and monitors AWS resource metrics.
- Metrics help track resource performance and utilization.
- CloudWatch Logs stores and helps analyze log data.
- CloudWatch Alarms monitor metric thresholds and can trigger notifications or actions.
- Cloud monitoring helps identify performance issues and operational problems.

**Practical Implementation**

- Explored the AWS CloudWatch dashboard.
- Reviewed available metrics.
- Explored CloudWatch Logs.
- Examined CloudWatch Alarms.
- Learned how EC2 monitoring works.

**Outcome**

Gained an understanding of AWS CloudWatch and its role in cloud-native monitoring.
